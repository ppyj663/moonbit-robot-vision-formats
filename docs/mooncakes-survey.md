# Mooncakes Survey

Before choosing this scope, the package index was checked with these keywords:

- `robot`
- `robotics`
- `vision`
- `camera`
- `depth`
- `slam`
- `yaml`
- `csv`
- `annotation`

Search results showed general document conversion packages and generic format
work, but no mature MoonBit package dedicated to offline robotics vision sidecar
formats and timestamp synchronization. This project therefore occupies a
specific but extensible ecosystem niche.

The package name and description should stay explicit about the offline bridge
boundary so it does not claim ROS runtime support that it does not provide.
